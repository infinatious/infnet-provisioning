# infnet-provisioning

Generic first-boot provisioning scripts for INFNET machines. No infrastructure-specific details.

- `post-install.sh`: shell prompt, base packages, automatic updates, MOTD (Ubuntu/Debian/AlmaLinux/Rocky).

Usage: `curl -sSL https://raw.githubusercontent.com/infinatious/infnet-provisioning/refs/heads/main/post-install.sh | sudo bash`
